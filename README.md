# 🎴 StudyFlow

تطبيق مذاكرة محلي يحوّل أسئلتك إلى جلسات مراجعة، تكرار متباعد، اختبارات تجريبية، وإحصاءات تقدّم. المستودع لا يحتوي على كتب أو سلايدات أو محتوى شخصي؛ حزمة `finals-2026-t3.json` العامة هي الاستثناء المقصود، ويمكن لكل مستخدم استيراد محتواه الخاص داخل متصفحه.

## المزايا

- أسئلة اختيار من متعدد ومطابقة ومسائل مع حلول.
- تكرار متباعد ومراجعة للأخطاء والأسئلة المستحقة.
- اختبارات تجريبية بوقت اختياري.
- إحصاءات للإتقان، المراجعة، الدقة، والمواد الأضعف.
- بحث، تمييز الأسئلة بنجمة، وخطة مذاكرة اختيارية.
- يعمل محليًا ويدعم التثبيت كتطبيق PWA عند استضافته.
- استيراد المحتوى من JSON؛ لا حاجة إلى تعديل كود التطبيق.

## تشغيل سريع

1. نزّل المستودع أو استنسخه.
2. افتح `index.html` في المتصفح.
3. مجموعتا فاينل CCCS-422 وCCSW-321 تُحمّلان تلقائيًا.
4. لإضافة محتوى خاص، افتح **الإعدادات ← المحتوى الدراسي ← استورد المحتوى** واختر ملف `studyflow-data.json`.

المحتوى الإضافي المستورد يبقى محليًا داخل المتصفح ولا يُدمج مع الحزمة العامة.

## إنشاء الأسئلة باستخدام Codex

ضع كتبك وسلايداتك مؤقتًا داخل مجلد اسمه `materials/`. هذا المجلد مستثنى من Git حتى لا تُرفع ملفاتك الدراسية بالخطأ. بعد ذلك افتح مجلد المشروع في Codex وأرسل له النص التالي:

```text
اقرأ جميع الملفات الدراسية الموجودة داخل materials/، بما فيها PDF وPPTX.

أنشئ ملفًا باسم studyflow-data.json صالحًا للاستيراد في StudyFlow، وفق المخطط الموجود في README.md.

المطلوب:
1. قسّم المحتوى إلى مواد ثم فصول أو محاضرات منطقية.
2. استخرج أسئلة اختيار من متعدد من المحتوى نفسه فقط، دون اختراع معلومات غير موجودة.
3. اجعل لكل سؤال 4 خيارات مع إجابة صحيحة واحدة، وحقل answer يبدأ من 0.
4. أضف شرحًا مختصرًا يوضح سبب صحة الإجابة، واذكر اسم الملف ورقم الصفحة أو السلايد في source عندما يمكن تحديده.
5. أنشئ IDs فريدة وثابتة للمادة والفصل وكل سؤال.
6. حافظ على لغة المصدر، ونظّف التكرار والأسئلة الغامضة.
7. إذا كان الملف ممسوحًا ضوئيًا، استخدم OCR وعلّم أي نص غير واضح بدل تخمينه.
8. لا تعدّل index.html، ولا تضع الكتب أو السلايدات داخل Git، ولا ترفع studyflow-data.json إلى المستودع العام.
9. تحقّق من JSON ومن جميع الإجابات والمراجع قبل الانتهاء.
10. أخبرني بعدد الأسئلة الناتجة لكل مادة وفصل وأي صفحات لم تستطع قراءتها.
```

للكتب الكبيرة، اطلب من Codex العمل على فصل واحد في كل مرة ثم دمج النتائج مع الحفاظ على المعرّفات الفريدة.

## صيغة `studyflow-data.json`

```json
{
  "version": 1,
  "subjects": {
    "COURSE-101": {
      "name": "اسم المادة · COURSE-101",
      "code": "COURSE-101",
      "color": "#38bdf8",
      "chapters": [
        {
          "id": "course101-ch01",
          "num": "01",
          "label": "Chapter 1 · عنوان الفصل",
          "questions": [
            {
              "id": "course101-ch01-q001",
              "q": "نص السؤال؟",
              "choices": ["الخيار الأول", "الخيار الثاني", "الخيار الثالث", "الخيار الرابع"],
              "answer": 0,
              "explanation": "سبب صحة الإجابة.",
              "source": "book.pdf · page 12",
              "src": "source"
            }
          ],
          "practice": [
            {
              "id": "course101-ch01-p001",
              "q": "مسألة تطبيقية اختيارية",
              "solution": "الحل المشروح"
            }
          ]
        }
      ]
    }
  },
  "schedule": {
    "plan": [],
    "exams": []
  }
}
```

قواعد مهمة:

- `answer` هو رقم الخيار الصحيح ويبدأ من `0`؛ الخيار الأول = `0` والرابع = `3`.
- يجب ألا يتكرر أي `id` داخل الملف.
- `schedule` اختياري، ويمكن تركه فارغًا كما في المثال.
- التطبيق يتحقق من بنية الملف قبل الاستيراد ويرفض الأسئلة غير الصالحة.

## الخصوصية

- المحتوى المستورد يُحفظ في `localStorage` داخل متصفحك فقط.
- ملفات `materials/` و`studyflow-data.json` ونسخ التقدم وملف التقويم مستثناة من Git افتراضيًا.
- نشر التطبيق على GitHub Pages ينشر حزمة الفاينل العامة فقط، ولا ينشر أي محتوى خاص استوردته داخل المتصفح.
- لا تضع رموز GitHub أو كلمات المرور أو بيانات شخصية داخل ملف المحتوى.
- إذا مسحت بيانات المتصفح، استخدم زر **صدّر المحتوى** أولًا للاحتفاظ بنسخة احتياطية.

## ملفات المشروع

- `index.html` — التطبيق.
- `finals-2026-t3.json` — حزمة الفاينل العامة المدمجة (مادتان، 210 أسئلة).
- `manifest.webmanifest` و`icon-512.png` — تثبيت PWA.
- `sw.js` — عامل الخدمة.
- `README.md` — دليل الاستخدام وصيغة البيانات.

## النشر المجاني

يمكن نشر التطبيق الفارغ عبر GitHub Pages:

1. افتح **Settings → Pages** في المستودع.
2. اختر الفرع `main` والمجلد الجذر.
3. احفظ الإعدادات.

بعد النشر يستطيع كل مستخدم فتح الرابط واستيراد ملفه محليًا، من دون أن تظهر أسئلته للآخرين.
