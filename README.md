# 🎴 StudyFlow · Security+

منصة مذاكرة محلية مخصّصة حاليًا لشهادة **CompTIA Security+ SY0-701**. النسخة المنشورة لا تحتوي على أي مادة جامعية أو محتوى Web/CSS/JavaScript.

## المحتوى المدمج

- مادة واحدة فقط: `SEC-PLUS`.
- 5 Domains تغطي منهج SY0-701 كاملًا.
- 28 Objective، ولكل هدف ملاحظات مراجعة مستقلة.
- 987 سؤالًا: 876 اختيارًا من متعدد و111 سؤال مطابقة.
- موعد الهدف المبدئي: 22 أغسطس 2026.

الملف العام الوحيد للأسئلة هو `security-plus-sy0-701.json`. يمكن استرجاع المحتوى السابق من تاريخ Git، لكنه غير موجود في النسخة المنشورة الحالية.

## المزايا

- جلسات حفظ واختبارات شاملة حسب الـDomain أو الـObjective.
- أسئلة اختيار من متعدد ومطابقة تفاعلية.
- تكرار متباعد، مراجعة الأخطاء، والأسئلة المستحقة.
- اختبارات تجريبية، بحث، أسئلة مميزة، وإحصاءات تقدّم.
- حفظ التقدم محليًا مع مزامنة Gist مشفرة اختيارية.
- استيراد ملفات خاصة بصيغة JSON؛ تبقى داخل المتصفح ولا تُرفع إلى GitHub.
